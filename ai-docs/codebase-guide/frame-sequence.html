Engine → JS 帧逻辑 → Root::frameMove(Begin/Process/End) → ForwardPipeline → GFX 提交/呈现

② 命令录制与 GPU 提交（装饰器链 → 双后端）

主线程 CommandBufferAgent 入队 → 渲染线程执行 → Vulkan vk* / GLES3 gl*

sequenceDiagram autonumber participant FP as ForwardPipeline participant CBA as CommandBufferAgent participant MQ as MessageQueue participant RT as RenderThread participant VK as CCVKCommandBuffer participant GLES as GLES3PrimaryCB participant VQ as VKQueue participant GC as GLES3Queue FP->>CBA: begin / beginRenderPass / bind* / draw / end Note over CBA: 每个方法 ENQUEUE_MESSAGE 入队 CBA->>MQ: enqueue(lambda actor->xxx) FP->>CBA: flushCommands() CBA->>MQ: flushMessages() then kick MQ->>RT: 渲染线程执行 actor->begin..draw..end alt Vulkan 后端 RT->>VK: begin -> vkBeginCommandBuffer RT->>VK: beginRenderPass -> vkCmdBeginRenderPass RT->>VK: bindPipelineState -> vkCmdBindPipeline RT->>VK: bind* -> vkCmdBindDescriptorSets / vkCmdBindVertexBuffers RT->>VK: draw -> vkCmdDrawIndexed RT->>VK: end -> vkEndCommandBuffer RT->>VQ: submit -> vkQueueSubmit else GLES3 后端 RT->>GLES: begin (重置状态机) RT->>GLES: beginRenderPass -> glBindFramebuffer/glViewport/glClear RT->>GLES: bind* (仅缓存) RT->>GLES: draw -> bindStates -> glDrawElements RT->>GLES: end (补发延迟 GL 状态) RT->>GC: replay -> cmdFuncGLES3ExecuteCmds (gl* 同步发出) end

说明：基类 gfx-base/GFXCommandBuffer 仅实现 initialize/destroy，begin/end/draw/execute 为纯虚；Vulkan 后端直接调用 vk*（VKCommands.cpp 不含 cmdBegin/cmdBind* 包装，仅用于资源创建/拷贝）；GLES3 的 begin/end 不立即产生 gl*，真正 gl* 在 bindStates → cmdFuncGLES3BindState 中按序发出。坐标详见 frame-flow.html。
